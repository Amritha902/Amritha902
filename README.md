### 🚀 What I'm building

**[PromptComplete](https://github.com/Amritha902/promptcomplete)** — the prompt
box, upgraded. Gmail has Smart Compose and your editor has Copilot, but the box
you type AI prompts into has nothing. So I built it: inline ghost-text
autocomplete that **learns how you write**, entirely on your own device.

- An interpolated **Kneser–Ney language model** trained on your own prompts
- A weighted **trie** and a Damerau–Levenshtein **BK-tree** on the hot path
- **Beam-search decoding** with confidence gating — silence beats a wrong guess
- 100+ automated tests, reproducible benchmarks, and a live in-browser demo
